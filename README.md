# LSS Prognostic Models

Course project repository (UW 596, Fall 2026) — project management plan, code, and materials.

**Live site:** https://aaronzh11.github.io/LSS-Prognostic-Models/

## Repository layout

| Path | What goes here |
|------|----------------|
| `docs/` | The public website. `docs/index.html` is what GitHub Pages serves. |
| `code/` | Analysis / modeling code. |
| `data/` | Data **pointers and small derived files only** — no PHI, no raw clinical data. |
| `materials/` | Slides, drafts, references, meeting notes. |

## Updating the website (weekly)

**Option A — edit on GitHub (fastest for small edits)**

1. Open `docs/index.html` on github.com
2. Click the pencil icon, edit, then "Commit changes"
3. The live site updates in ~1 minute

**Option B — edit locally**

```bash
git pull
# edit docs/index.html
git add -A
git commit -m "Weekly progress update: <date>"
git push
```
